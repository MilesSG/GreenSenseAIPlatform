# 🌿 GreenSense AI 平台

基于深度学习的遥感影像植被识别与提取研究平台

## 🚀 项目介绍

GreenSense AI 是一个专为遥感影像植被识别与提取研究设计的前端界面，能够通过多种深度学习模型（U-Net、U-Net++、FCN、DeepLab V3+等）分析遥感图像，提取植被信息，并对比不同模型的性能表现。

## 🛠️ 技术栈

- 框架：Vue 3 ⚡
- 语言：TypeScript 📝
- 构建工具：Vite 🔥
- 状态管理：Pinia 🍍
- UI 组件库：Element Plus 🧩
- CSS 框架：Tailwind CSS 💨
- 图表库：ECharts 📊

## ✨ 主要功能

### 📊 仪表盘
- 数据统计卡片：已处理图像数量、识别精度、植被覆盖率等关键指标
- 最近处理的遥感图像预览
- 重要指标趋势图表

### 🔍 图像分析
- 遥感图像上传和处理
- 多模型处理结果对比显示
- 支持网格布局显示不同模型的处理结果
- 图像悬停效果展示处理前后对比

### 📈 模型性能分析
- 各模型在多维指标上的全面对比（精度、召回率、F1分数、推理速度等）
- 性能雷达图直观展示模型优势
- 不同环境条件下（晴天、多云、雨天、雾天）的模型表现
- 性能与能耗平衡分析
- 时间趋势展示模型性能改进
